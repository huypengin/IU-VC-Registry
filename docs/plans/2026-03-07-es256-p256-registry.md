# ES256 P-256 Registry Migration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the registry's Ed25519 issuer key handling with ES256 on P-256 for generated DID documents, stored key material, environment configuration, and status-list signing.

**Architecture:** Move the registry's crypto primitives from Ed25519 raw multibase keys to P-256 JWK-based keys. Keep the CLI and registry build flow the same shape, but update all outputs, config loaders, and signing code to emit `JsonWebKey2020` verification methods and sign with an ES256-capable Data Integrity suite.

**Tech Stack:** TypeScript, Node.js `crypto`, Commander, Vitest, jsonld-signatures, Digital Bazaar Data Integrity libraries
